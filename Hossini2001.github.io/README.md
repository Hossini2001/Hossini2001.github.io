## Editing

Everything is in `index.html`: plain HTML and CSS, no build step. To update the site, edit that file and commit; GitHub Pages republishes within a minute or two.

- **CV:** upload your CV as `cv.pdf` in the repo root (the CV links already point there).
- **Photo:** upload `photo.jpg` and replace the `HE` initials in the header with `<img src="photo.jpg" alt="...">`.
- **Placeholders:** anything highlighted in orange on the page (`class="todo"`) still needs your real details. Remove the `todo` class once you've filled it in.
